Privacy Policy

This application is a personal tool used solely by its owner to schedule and publish posts to their own LinkedIn profile via LinkedIn's official API.

It does not collect, store, or share data belonging to any third party. Authentication tokens are stored securely (as an encrypted GitHub Actions secret) and used only to authorize posting on behalf of the account owner. No data is sold, shared with advertisers, or used for any purpose beyond enabling the owner's own content publishing.
